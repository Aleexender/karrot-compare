# 01. 중고물품 판매 게시글 등록 API — 설계 프롬프트 (원문)

요구사항 중고물품 판매 게시글 API.
한 유저는 여러개의 물건을 게시글을 작성할수 있다. (게시글은 제목, 내용, 가격, 네고 가능, 판매 상태로 존재한다)
이는 POST 이며 API path는 "/posts" 복수 로 진행한다.
 게시글은 상태가 존재한다.(판매중, 판매완료, 판매중지). 또한 게시글에서 네고가능(boolean)이 존재한다.
또한 해당 게시글의 물건이 어떤 타입인지 유저가 정할수 있다.( IT기기, 옷/패션, 가전제품)
도메인은 items, users,  item_categories 이렇게 있다.
여기서 users 는 item_categories 를 몰라야한다.
인터페이스는 repository만 존재하며 그 외에는 존재하지 않는다.(일단은)
또한 로그인은 구현하지 않을것이다. 그냥 로그인 기능이 있다는 전재하에 진행하자.

엣지 케이스는 아래와 같다.
유저가 게시글 등록을 동시에 두번 연속으로 빠르게 누른경우 한개만 올라가야한다.
유저가 가격을 등록하지 않고 올린경우 400대 에러로 처리해야한다(유저 잘못)
유저가 제목을 올리지 않고 올리는경우도 400대 에러로 처리해야한다(유저잘못).
내용은 빌수 있다.

예상 트래픽은 아래와 같다.
MAU : 231만명
누적 가입자 수 430만명
주간 활성 이용자 수 140만명 으로 가정.
DAU : 120만

인기 게시글인 경우 12만으로 잡겠다.

완성기준은 유저들이 동시 작성 1만건중에 9500건 써지면 통과
